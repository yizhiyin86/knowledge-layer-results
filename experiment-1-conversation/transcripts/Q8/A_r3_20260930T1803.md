## Final answer

I haven't built this ranking. Using patient-level data to set incentive-comp (IC) bonuses is a restricted use, so it needs sign-off from Compliance, Privacy and whoever manages the data license before anyone runs it.

**What I found**
- **Rep-level abandonment only comes from patient-level data.** `RAW_3P.PATHPT_LVL` is a third-party patient-level feed (114,958 rows). Each row has a patient ID (`PAT_KEY`), claim date, product code (NDC), prescriber ID, plan and an abandonment flag (`ABNDN_FLG`). The only way to tie abandonment to a rep is to link each patient to their prescriber, then to that prescriber's territory and rep.
- **The claims table can't do it.** `RAW_3P.CLMLNS_ADJ` also has an abandonment flag, but it has no prescriber field, so it can't be linked to reps.
- **Nothing in the warehouse clears this data for comp.** `PATHPT_LVL` has no table, column or schema comments and no governance tags. There's no documentation saying it's approved for incentive comp. The license and privacy terms that govern it aren't stored here.

**Why I stopped**
- **License and privacy terms.** Third-party patient-level data is usually licensed, and privacy-certified as de-identified, for analytics only. Rep compensation is typically excluded. Linking patients to prescribers to reps to pay can also break the conditions that keep the data classed as de-identified.
- **Compliance risk from the incentive itself.** Paying reps based on whether patients abandon their prescriptions rewards reps for influencing patient behavior. That carries anti-kickback and patient-steering risk no matter which data source is used.
- **Your role.** You're asking as a comp analyst, and nothing I can see approves that role to use patient-level data for this purpose.

**What I can do now**
1. **IC scoring on the standard sources:** each rep's prescriptions (TRx) against their quarterly goal, using `RAW_3P.RXT_WKLY`, `CORE.IC_GOAL` and the rep roster. I can run this right away.
2. **Abandonment as a non-comp report:** abandonment rates by territory or region, grouped so no individual patient can be picked out, for market-access or coaching purposes only.
3. **The ranking you asked for:** if Compliance, Privacy and the data-license owner confirm in writing that this data is cleared for IC, I'll build it. I'd also want them to approve how abandonment is defined and credited to reps.
